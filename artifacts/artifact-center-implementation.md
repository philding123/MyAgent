## 2. 用户可见行为

- 任务顶栏新增“产物”按钮；右侧集中列出成功写入的工作文件和正式交付文件。
- 正式交付默认在右侧预览；手动折叠后当轮不强制展开，下轮交付可重新展开。
- 聊天卡片和右侧列表共享选择；会话之间隔离选中、折叠状态。
- 重开会话、重启 daemon 后从持久消息恢复产物；失败或被拒绝的工具不产生可用卡片。
- 提供“打开所在文件夹”“默认应用打开”“复制路径”“独立窗口”“源码／成品”操作。
- Markdown 和 HTML 支持成品显示；HTML 在空权限 sandbox iframe 中展示，不执行脚本、不外联、不暴露 preload。
- PDF、图片及 Office 复用共享控制器；明确显示大小、页数、工作表和文本截断提示。
- 远端文件明确标识，不交给本机文件管理器；尚无云端下载协议，云端 present_file 明确拒绝。

## 3. 关键实现和安全边界

- `app/shared/artifacts.js`：版本化元数据、容错历史解析和去重、默认应用扩展名白名单。
- `app/daemon/artifacts.js`：会话归属、登记记录、常规文件及原路径／realpath 沙箱校验。
- `app/daemon/index.js`：产物先落库再广播；持久化失败不广播产物；新增 artifacts.list/resolve；预览读取增加 realpath 校验。
- `app/engine/index.js`、`tools/index.js`、`tools/present.js`：仅成功结构化结果产生工作／交付产物，区分本地和远端。
- `app/main/artifact-actions.js`：仅可信主窗顶层来源，原生 API 操作，不拼接 shell；每次默认应用打开都确认，120 秒超时拒绝，批准后再次校验。
- `app/renderer/src/artifact-center.js`、`artifact-center.css`：右侧面板、会话状态和异步切换失效控制；窄窗给输入区域留位。
- `app/renderer/src/preview-renderer.js`：共享安全渲染、隔离成品、Office 前置净化、资源销毁、过期结果不覆盖当前目标。
- 保持两个 IPC handle，不修改 vault 存储和引擎模式策略，不增加模型可调用的系统打开工具。

默认应用打开允许受支持文档、位图和有限文本类型；HTML／SVG／脚本／快捷方式／可执行文件不允许通过该入口启动。PPTX 静态预览可能省略动画、交互和非位图绘图，并有明确提示；不宣称与 Office 原生渲染完全一致。
