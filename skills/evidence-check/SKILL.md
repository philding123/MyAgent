# Evidence Check（核对"有出处的解释"）

来源：逆向复刻工作流第 3 步（zhaoxuya520/reverse-skill 方法学，2026-10 提炼）。
前置：第 2 步分析已完成，产出了带依据的结论。本技能把"结论"升级成"可核对的结论"。

## 工作流

1. **Evidence 记录表**：逐条列出本次分析的全部结论，每条必须带：
   - 结论本身（一句话）；
   - 出处：具体读了哪些文件、哪几段代码（`文件路径:行号` 或 `文件路径:函数名`），
     依据是那段内容的什么（调用关系/常量/分支/数据流）。
   - 没有出处的结论必须标注 `❓ 未证实`，不得混入已证实结论。

2. **证据链校验**：自查一遍——
   - 每条结论能否找到出处？出处是否真的支持该结论（不是"看起来相关"）？
   - 证据链断裂（出处缺失、出处与结论不符、纯猜测）→ **退回补分析**，
     不带着猜想进入下一步（复刻/交付/汇报）。

3. **大白话复述**：用一段完全不懂编程的人能听懂的话，把这个功能的实现原理讲清楚
   （打比方、讲流程，不堆术语）。

## 输出格式

```
## Evidence 记录
| # | 结论 | 出处（文件:行号/函数） | 依据 |
|---|---|---|---|
| 1 | … | src/x.js:42-58 | 循环重置计数器… |
| 2 | … | ❓ 未证实 | 需补分析：… |

## 大白话原理
（讲给完全不懂编程的人听）
```

## 红线

- 结论找不到出处时，明说"未证实"，绝不编造行号或文件名。
- 本技能只核对与表述，不修改任何文件（read-only 工作流）。
