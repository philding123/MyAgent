## 1. 问题（截图审计，before 见 PR 附图）

| 区域 | 问题 |
|---|---|
| 整体 | 冷灰平涂、层次靠硬边框；色板是 wb 青绿 `#00c29a` 大面积点缀，显廉价 |
| 控件 | 窗口按钮/搜索/发送用 Unicode 字形（`— □ ✕ ⌕ ↑`）；设置导航用 emoji；原生 `<select>`/复选框 |

## 2. 设计语言（参考原则，不复制任何产品品牌）

1. **暖中性底 + 单一克制强调色**：纸感暖白/暖黑分层，强调色只用于焦点、选中、链接、状态。
2. **墨色主操作**：主按钮/发送键用墨色（浅色主题近黑、深色主题近白），强调色不做大面积按钮。
3. **层次靠阴影与留白而非边框**：卡片/浮层多层柔和阴影，边框降到 8–10% 不透明度。
4. **大圆角、紧凑节奏**：composer 20px、卡片 14px、控件 8px；4px 网格。
5. **克制动效**：浮层 140ms 缩放淡入、消息 220ms 上浮淡入、窗口淡入；`prefers-reduced-motion` 全部关闭。
6. **统一线性图标**：1.3–1.4px 描边 SVG，16px 网格；去掉所有 emoji/字形图标。

## 5. 窗口弹出体验（app/main/windows.js）

- `show:false` + `ready-to-show` 后再显示（冒烟模式保持不显示），`backgroundColor` 取新 token → 无白闪。
- 显示时窗口淡入（win32/darwin `setOpacity` 0→1，约 160ms；Linux 无透明度 API 直接显示）。
- 设置、搜索窗 **以主窗为 parent** 且**居中于主窗**（主窗可见时）；预览窗保持独立（文档要能放到主窗后面），但首开也相对主窗错位居中。
- 搜索面板：失焦即关闭、Esc 关闭（冒烟/审计接缝模式下不做失焦关闭，避免测试驱动时被关）。
- 设置窗：Esc 关闭。

## 6. 组件改造清单

- **band/conv-bar**：窗口按钮 SVG（最小化/最大化/关闭），菜单标签降为 `--text-2`。
- **侧栏**：品牌行加 logo 标（圆角方块 + 字母），nav 激活态 `--gray-4` + 600 字重，会话行 hover/active 柔化，底部用户行去硬分隔改淡分隔。
- **首页**：hero 标题 32px / -0.02em；场景 pills 改分段控件；chips 与建议行改柔和卡片，hover 微抬。
- **会话**：用户消息右对齐气泡（≤78%）；助手正文 15px/1.7；代码块暖黑底 + 语言标签 + 复制按钮；表格圆角外框 + 表头底色；工具条目改为状态点 + 名称 + 摘要的低调 pill；计划卡片勾选圆点；composer 卡片 20px 圆角 + 聚焦环 + 上方渐隐过渡；发送键墨色圆钮 + SVG 箭头。
- **浮层**：`.pop-menu`/`#mode-menu` 12px 圆角 + `--shadow-md` + 缩放淡入；`#expert-modal` 背景模糊 + 卡片入场；确认条改为 composer 上方的浮起卡片。
- **设置窗**：标题栏显示「设置」；导航 emoji → SVG；面板标题 20px + 卡片 14px；输入框 34px + 聚焦环；`select` 自定义箭头；复选框 → 开关；`window.confirm()` → 页内确认对话框（`uiConfirm`，Promise，Esc=取消，Enter=确认）。
- **搜索面板**：大号输入（52px）、分段 tabs、结果行（图标 + 标题 + 摘要、键盘激活高亮）、底部 `kbd` 键帽提示。
- **预览窗**：自带标题条 + 窗口按钮；内容卡片阴影。
- **splash**：同 token（暖底、logo 标、墨色进度条）。
